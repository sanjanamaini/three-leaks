# The Three Leaks

**Where do Indian equity mutual fund investors lose their returns: to commissions, to luck dressed up as skill, or to their own timing? And can any of it be avoided in advance?**

Status: in progress (stage 0, scaffold and pre-registration). Results are added stage by stage; every number is regenerated by one command.

## The idea in one paragraph

An investor in an actively managed equity fund can trail a cheap index alternative in three separate places. The **commission leak** is the distributor fee inside a regular plan; India makes it unusually clean to measure, because since 2013 every fund has a direct plan with the same portfolio and manager. The **skill leak** is the gap between what managers deliver and what the market, size, value and momentum factors would have paid anyway, after separating real skill from luck. The **timing leak** is the gap between the fund's return and the investor's money-weighted return, created by buying after rallies and selling after falls. This project measures all three on one open, survivorship-free dataset, tests whether any can be avoided by selecting funds in advance (including with machine learning), and turns the results into a scorecard an investor or a platform can use.

## Questions (pre-registered in [`PREREGISTRATION.md`](PREREGISTRATION.md))

1. How large is the direct-minus-regular return gap of twin plans, and did SEBI's 2019 expense-ratio cut shrink it?
2. After fees, what share of funds have truly positive alpha once luck is controlled for (false discovery rate, bootstrap)?
3. How far do investors' money-weighted returns trail the funds' time-weighted returns, and is their timing worse than random?
4. Can simple rules or machine learning pick funds with positive future alpha, out of sample?

## Reproduce

```
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
make all        # download, build panels, run every analysis, write results and the report numbers
```

## Data

Downloaded from the original sources by `make data`; raw files are never committed. Sources and licences: [`DATA.md`](DATA.md).
