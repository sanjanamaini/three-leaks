How to read this

Regular-plan cost is what the regular plan returned less than its direct twin over the last three years. Both plans hold the same portfolio with the same manager, so the gap is the price of distribution.

Alpha is the direct plan's average return beyond what the market, size, value and momentum factors (IIMA data library) explain, after the direct plan's own expenses. Many funds show positive alpha by chance. The q-value is the estimated share of false discoveries if this fund, and every fund with stronger evidence on the same side, were called skilled (or unskilled), following Barras, Scaillet and Wermers (2010). The verdict uses q at or below 0.10.

Expected alpha shrinks each fund's alpha toward the average fund, more so when the estimate is noisy (empirical Bayes). Chance alpha > 0 is the estimated probability that the fund's true alpha is positive. Both discount luck; the raw alpha does not.

R-squared near 1 means the fund's returns are almost fully explained by the factor portfolio, which an index fund can deliver for less.

Past alpha is a weak guide to future alpha; the project's out-of-sample tests are in the report. This is research, not investment advice.
